# STATE — 루프 실행 기록

이 파일이 **실행 간 유일한 기억**이다. 에이전트는 매번 빈 컨텍스트에서 시작하므로,
여기 적히지 않은 것은 다음 실행에서 존재하지 않는 것과 같다.

## 기록 위치가 둘인 이유

이 파일은 **PR 브랜치에만 커밋**된다. 따라서 PR을 만들지 않은 실행
("게이트 차단", "처리 대상 없음")은 여기 남길 방법이 없다.

| 기록처 | 대상 | 성격 |
|---|---|---|
| **런 로그 — 이슈 #128 코멘트** | **모든 실행** | 유일하게 빠짐없는 기록 |
| `STATE.md` (이 파일) | PR을 만든 실행만 | 저장소에 남는 누적 이력 |

지난 실행을 확인할 때는 **런 로그를 먼저 본다.** 이 파일은 요약본이다.

## 기록 규칙

- PR을 만든 실행은 이 파일에도 항목을 추가하고 **같은 PR 브랜치에 커밋**한다
- 최신 항목을 **맨 위**에 추가한다 (역순)
- 항목이 30개를 넘으면 오래된 것부터 `## 보관` 섹션으로 접는다
- 기존 항목을 수정하지 않는다. 추가만 한다

## 항목 형식

```markdown
### <YYYY-MM-DD HH:MM> — <결과>

- **회수:** 없음 | #NN 락 해제 (사유)
- **게이트:** 통과 | 차단 (열린 agent-loop PR #NN)
- **후보:** #NN, #NN (자동 처리 가능으로 판정된 이슈)
- **선택:** #NN — <고른 이유, PRIORITY 근거>
- **탈락:** #NN (사유), #NN (사유)
- **결과:** PR #NN 생성 | needs-human #NN | 처리 가능 이슈 없음 | 실패 (사유)
- **검증:** lint ✅ build ✅ | lint ❌ (에러 요약)
- **비고:** <다음 실행이 알아야 할 것>
```

`<결과>`는 다음 중 하나:

| 값 | 의미 |
|---|---|
| `PR 생성` | 정상 완료. 사람 리뷰 대기 |
| `게이트 차단` | 진행 중 작업이 있어 아무것도 하지 않음 |
| `처리 대상 없음` | 자동 처리 가능한 이슈가 없음 (정상) |
| `에스컬레이션` | `needs-human`으로 넘김 |
| `실패` | 작업 중 문제 발생. 사유 필수 |
